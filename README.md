## About

我平时会做一些小项目、脚本和工具，享受把想法一步步变成能跑起来的东西的过程。也喜欢逛开源项目，看看别人是怎么写代码、怎么解决问题，用实际案例来扩展自己的理解。

除了写代码，我也关注心理健康议题，认为精神类疾病应该被更多人理解，而不是被标签化、回避或误解。
